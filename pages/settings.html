Siteler (GitHub kontrollü)

Yeni sekmedeki site kutuları bir GitHub JSON dosyasından gelir. Depo linki, blob dosya linki, raw link veya gist yapıştırabilirsin. Depo linkinde kökteki sites.json okunur.

Kendi sitelerim (yerel)

JSON biçimi

{
  "name": "Benim listem",
  "sites": [
    { "name": "Site adı", "url": "https://ornek.com", "category": "Film", "icon": "https://.../logo.png" }
  ],
  "blockHosts": ["reklam-agi.example"]
}
Düz dizi [ {...}, {...} ] ve "categories":[{"name":"..","sites":[..]}] biçimleri de desteklenir. blockHosts ile reklam alan adlarını da GitHub'dan yönetebilirsin.

Geçmiş

Ghost Browser

Film izlemeye odaklı Electron tabanlı tarayıcı. Kendi oynatıcısı (HLS/MP4/WebM, altyazı), reklam engelleyici, GitHub kontrollü site listesi ve telefondan QR ile kumanda.

DRM'li (Widevine) servisler — Netflix, Disney+ vb. — stok Electron'da çalışmaz. Yasal ücretsiz kaynaklar ve doğrudan video bağlantıları sorunsuz oynar.
